# GeoTurf Planning

This directory is the authoritative work system for GeoTurf. It records what
the project intends to do, why a decision was made, and the verified state of
each piece of work.

## Start Here

- [Roadmap](ROADMAP.md) - ordered outcomes for the library.
- [Path To 1.0](V1.md) - planned compatibility milestones and release gates.
- [Work System](WORKFLOW.md) - the operating rules for people and agents.
- [Current Plans](plans/README.md) - actionable, bounded work.
- [Domain Context](CONTEXT.md) - terms and invariants used when planning.
- [Architecture Review](ARCHITECTURE_REVIEW.md) - the August 2026 assessment.
- [ADRs](adr/README.md) - durable decisions only.

## Source Of Truth

Do not create an issue tracker item merely to duplicate a plan. A plan under
`docs/plans/` is the work queue until the project deliberately adopts a second
system of record.

Generated API documentation belongs in `doc/`; planning and design records
belong here.
